# 当前交互需求

交互基线：**v0.19 UX027**。本文件合并 UX001–UX027 中仍有效的规则；UX024 调整详情首行并隐藏每日 AFP；UX025 移除圆圈 tooltip；UX026 将登出与重新登录放入设置子菜单；UX027 增加应用更新检测与关于窗口下载入口。圆圈直径为 112dp。版本覆盖链与实施流水从 Git 历史追溯。业务范围见 [产品需求](product-requirements.md)，格式及接口参数见 [契约](../contracts.md)。

T057 接受的是对应历史代码与自动检查；人工验收 T-007 仍 pending。个人版应用内直连登录及应用版本检测已实现；Managed Runtime 更新 / 回滚的历史验收边界仍见 [差异与限制](../implementation-gaps.md)，不作为 v0.15 已接受规则回填。

## 启动与打开（UX001、UX002、UX010–UX012）

- 应用常驻托盘。首次运行显示悬浮圆圈并写首启标记；之后无参数启动静默驻留。`--show` 强制显示圆圈。
- 第二实例通过 IPC 唤起已有实例，随后静默退出；不产生第二个常驻进程、托盘图标或提示对话框。信号失败须返回失败。
- 托盘左键切换圆圈；圆圈左键或 Enter / Space 打开全部额度详情。打开、重复唤起与设置只展示已有状态，均不触发额度查询。
- 托盘切换按本次 MouseDown 捕获的真实可见性决定，一次 Click 后清除捕获；没有 MouseDown 的 Click 使用当前可见性。详情失焦隐藏由单一延迟机制裁决，菜单或设置打开期间抑制误隐藏，避免一次操作先隐藏后重开。
- 首启标记只记录版本与日期，不含身份、额度或凭据。离线测试不写用户标记、不碰真实单例 IPC。

## 查询与展示更新（UX011、UX013）

- 启动后立即后台查询一次。圆圈或详情任一可见时每 **10 秒**轮询；两者都隐藏时每 **5 分钟**轮询。仅设置弹窗可见不提速。
- 可见性变化只调整现有 Timer 间隔，不立即查询；相同间隔不重复赋值。退出后不重启计时器。
- 启动、定时、手动刷新共用一个在途请求；重复触发不并发、不排队，也不取消已有查询。
- 等待期间保持数据、焦点与滚动，不显示“刷新中”、阶段、慢响应或取消过程态；新结果返回后一次提交。明确身份变化可以提前清除旧数据。
- 相同展示语义只更新元数据与时间，不重建卡片或子控件、不重置焦点与滚动；不同语义统一替换并释放旧控件。
- 无缓存且尚无结果时固定显示“暂无数据”。普通失败保留历史与原时间并给短提示；历史不伪装成最新数据。
- 跨重启快照、Same / Unknown / Mismatch 的清留规则见契约。

## 悬浮圆圈与内容选择（UX012、UX014）

- 圆圈置顶、无边框、不进任务栏；直径约 112dp（半径约 56dp），初始位于当前屏右下工作区，安全边距约 16dp。椭圆 Region 外点击穿透。
- 水位按剩余百分比呈现：0 空、100 满，未知为中性无水。圈内显示百分比与剩余额度；悬浮圆圈不显示 hover 或临时状态 tooltip。完整额度通过点击详情查看，保留无障碍描述。轻动画只重绘，不查询。
- 候选按接口产品 / 周期原顺序枚举，并标明有效百分比、未知、错误、未订阅或订阅未知。首次未配置时选第一个已知有效百分比周期；全部未知时取首个可展示条目。不取全局最低，不求和、平均或轮播。
- 已选目标缺失时保留选择并显示“暂无数据”，不暗换。只有已知有效订阅且周期百分比有限、处于 0–100 时显示水位；其他情况显示“剩余未知”。
- 选择跨启动记忆，只存产品稳定 key 与周期 label。默认计算不写盘；用户显式保存成功后立即按已有数据生效，不查询；失败保留原值并提示。
- 圆圈可拖动，限制在所在屏工作区内，支持负坐标多屏。超过拖动阈值不打开详情。位置只在本会话有效，不保存坐标。
- 圆圈失焦不隐藏；Esc / WM_CLOSE 隐藏而不退出。退出统一释放窗口、菜单、计时器和查询资源。

## 详情卡片（UX014、UX022、UX024）

- 详情只显示卡片，无独立标题操作栏、页脚、外围留白和固定最小高度。卡片首行依次显示订阅类型、最近更新时间与右侧刷新按钮；个人 Agent Plan 的周期行仅显示 5 小时、周、月，隐藏每日 AFP。单卡片窗口贴合实测尺寸；多卡片纵向排列，间距 10dp，仅在卡片之间留间距。
- 逻辑宽度 406dp，并限制在工作区内。高度按真实布局两次测量：先全宽测量，溢出才扣滚动条宽度重排；高度上限为 `min(560dp, 工作区高度 - 16dp)`，超出才纵向滚动。不能按周期数猜测滚动或形成无限 resize 循环。
- 保留套餐名称、周期剩余百分比及进度、可用剩余绝对量和必要重置时间；移除风险汇总、紧张周期摘要、冗余身份横幅、首启长 banner、重复已用 / 总量与秒级倒计时。`0 < 剩余 < 1` 显示 `<1%`，真实 0 与 100 清楚可读。
- 空态、错误、未登录仍用消息卡片；缓存、过期和身份未确认状态紧凑显示在首个卡片内，原位更新。首行更新时间为最近成功查询时间，tooltip 保留完整日期；查询失败保持旧时间。首行刷新按钮复用手动刷新路径，在途请求不并发、不排队。
- 首次打开先确定最终尺寸再定位；优先圆圈左侧，其次右 / 上 / 下，不覆盖圆圈。均无法容纳时暂时隐藏圆圈，详情关闭后恢复；用户显式隐藏的圆圈不能被误恢复。
- 可见数据大小变化后按当前圆圈重新定位；同语义或仅查询时间变化不改尺寸。跨 DPI 重新打开须更新字体、padding、圆角并使布局缓存失效。
- 卡片可聚焦、可通过 Tab 访问；打开后焦点落在卡片或首个可聚焦内容，重复打开已有焦点时不强制重置。关键控件有可访问名称，100 / 150 / 200% DPI 与窄工作区不裁切关键内容。
- 详情本地右键菜单仅含 **刷新 / 复制摘要 / 设置 / 关闭**。打开菜单零查询并抑制失焦隐藏；关闭、Esc、失焦和 WM_CLOSE 隐藏详情，不退出应用。
- 视觉使用瓷白内容面、低对比边线、海军蓝 / 青绿强调；圆圈保持深色底。沿用自绘托盘图标，不新增依赖或字体资产。

## 共享菜单与设置（UX015、UX023、UX026）

- 圆圈与托盘共享右键菜单，第一级依次为 **设置**、**显示或隐藏悬浮窗**、**关于 / 诊断**、**退出 ark_left**；第一级不展示账号操作。
- 点击“设置”显式展开原生旁侧子菜单，屏幕边缘自动反向展开，不打开 modal，零查询。子菜单顺序为：**悬浮内容 / 登出 / 重新登录**。
- 登出取消正在进行的登录、查询与续期，清除本项目凭据、额度展示和缓存；成功后保持未登录，不隐式重新登录。凭据删除失败须明确报告未完成并允许重试。重新登录沿用手动回调流程，登录期间该子项显示“取消登录”；成功后再查询额度。登出处理中禁用两项账号操作，拒绝旧结果写回。
- “悬浮内容”的下级列出与选择弹窗相同的候选，当前项勾选。点击直接保存并立即生效；保存前重验当前候选；失败保留原值与勾选，给固定短提示“悬浮内容未保存”。无候选时只有禁用的“暂无数据”。
- 详情右键“设置”打开单实例选择 modal，标签为“悬浮内容”，包含原生 DropDownList 与保存 / 取消。Esc、取消和 Alt+F4 不保存；写失败保持弹窗打开并显示可读 inline 错误；空态禁用保存。
- 设置期间详情不因失焦隐藏，关闭设置回到原详情并保留焦点与滚动。从圆圈 / 托盘操作不强制打开详情。长候选通过下拉宽度与 tooltip 完整可读。

## 应用更新（UX027）

- “关于 / 诊断”为单实例窗口，显示当前应用版本、检查状态、“检查应用更新”和“打开下载页面”，另提供“ArkCLI 组件诊断”。应用更新与组件更新的按钮、状态及版本明确区分。
- 启动约 15 秒后后台检查 GitHub 最新正式发布，运行期间每 24 小时检查一次。自动与手动检查共用一个在途请求，不并发、不排队；检查中禁用检查与下载按钮。关闭窗口不结束应用，退出取消请求并忽略迟到结果。
- 发现更高数字版本且安装包已上传时，自动检查发送托盘通知，同一版本每次运行只提示一次；不打开详情、关于窗口或浏览器。手动检查通过窗口显示结果，无新版不通知；自动失败静默处理，手动失败固定文案并允许重试。
- 仅用户点击下载按钮才打开本仓库对应发布页；检查不写凭据、偏好或额度数据，不自动下载与安装。下载入口仅在有效新版状态启用，浏览器启动失败留在窗口提示重试。

## 锁定、动画与归位（UX016、UX017、UX020）

- 锁定默认关闭，仅阻止鼠标拖动；左键 / Enter / Space、菜单与显隐仍有效。锁定时超过拖动阈值的手势不误开详情；切换时释放 Capture、重置进行中手势。
- 减少动画默认关闭；开启立即停动画 Timer、重绘静态波面；关闭只在圆圈可见且 `0 < 剩余 < 100` 时重启动画。隐藏、端点、未知和 disposed 时不启动。
- 两个偏好跨启动保存，同值不写盘。失败保持全部旧偏好及勾选；无论圆圈可见或隐藏，均使用托盘 balloon，文案区分失败字段，不回显异常。成功不弹通知。
- 归位将圆圈显示在当前所在屏右下默认安全边距，未定位时取主屏，按该屏 DPI 缩放。先释放 Capture 并重置拖动；锁定不阻止归位。
- 归位时先隐藏详情并清自动隐藏标志，不自动打开详情；设置 modal 打开时不动作。不查询、不存坐标、不改变选择或偏好。

## 复制与本地快捷键（UX019、UX021）

- 有快照时，“复制摘要”或详情内有效 Ctrl+C 才写剪贴板；自动打开、刷新、渲染与状态变化不写。摘要包含全部已展示额度、周期、剩余量、重置时间与最后成功更新时间。
- 纯 formatter 是独立安全边界：不转写上游 `Error` / `Message` / `UnknownNote`，只用固定安全文案，不含身份、profile、凭据或 scope 指纹。未知不写作 0；缓存、过期、身份未知与 total=0 明确标记；空 product / period 安全处理。
- 复制零查询、不重建卡片；卡片 tooltip 短暂反馈“已复制”或“复制失败”（约 2 秒），不覆盖错误状态、不弹阻塞对话框。
- 精确 Ctrl+R 复用手动刷新路径，精确 Ctrl+C 复用复制路径。只在详情可见、启用、含焦点、未释放且设置 / 菜单未打开时生效；其他修饰组合走默认处理。
- 无快照时复制菜单禁用；有效 Ctrl+C 可消费按键但不写剪贴板。隐藏、未聚焦、modal 或菜单打开时不动作、不打开窗口。无全局热键、SendKeys 或桌面输入注入。

## 恢复与交付入口（UX005、UX018）

未登录、CLI 缺失、失败需提供登录指引、本地设置指南或重试等可恢复动作；上游错误使用固定安全文案。v0.15 基线不自动执行登录或安装；后续个人版直连登录和应用版本检测已实现，Runtime 更新 / 回滚验收边界另见差异记录。

双击 `start.cmd` 复用同版实例，平滑替换项目内旧版实例；具体目标、白名单、WM_QUIT 与失败规则见契约。自动检查不能替代真实托盘、视觉、多屏、读屏或剪贴板验收，未测项统一见 [verification.md](../verification.md)。
