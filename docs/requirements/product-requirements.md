# 产品需求

正式业务基线：**v0.6，R001–R005**。v0.2 将 Agent Plan 个人额度登录与查询切换为浏览器 SSO → PKCE → 临时 STS → GetAFPUsage；v0.3 要求用户复制完整回调 URL 并主动输入提交，取代自动回调接收，支持复制登录链接、输入校验及取消；v0.4 在左侧详情弹窗隐藏每日 AFP，仅显示 5 小时、周、月，首行将最近更新时间与订阅类型并列，右侧提供刷新按钮；v0.5 提供设置子菜单内的登出与重新登录；v0.6 增加应用版本检测与下载入口。原始数据保留四窗口与其他 ArkCLI 能力。原 Agent Plan / Coding Plan 订阅额度业务不包含账户余额或 Token 资源包。

用户目标是在桌面右下角常驻一个小插件，点击即可查看订阅剩余额度、周期与重置时间。Windows 托盘、WinForms 与布局参数是工程设计选择。

当前交互规则见 [交互需求](interaction-improvements.md)，数据与存储规则见 [契约](../contracts.md)。实现差异见 [差异与限制](../implementation-gaps.md)，验收证据见 [verification.md](../verification.md)。

## 业务需求

| 编号 | 要求 | 验收条件 |
| --- | --- | --- |
| R001 | Windows 托盘常驻图标，点击展示轻量浮窗 | 可唤起、收起；窗口位于工作区内，适配多屏与 DPI。Windows 可能将图标收入折叠区，不承诺强制可见 |
| R002 | 以剩余百分比为主展示当前身份订阅的产品及各周期；有字段时展示剩余绝对量与重置时间 | `percent=25` 表示已用 25%，主显剩余 75%；缺失数值与真实 0 区分；部分错误不遮蔽可用周期 |
| R003 | 区分查询失败、未登录、未订阅及部分桶错误，并提供恢复指引；支持登出和重新登录；直连区分登录、续期、401/403、签名与网络错误 | 失败和未知不显示为 0；未订阅与失败不同；错误提示不泄露上游原文或凭据；个人额度不受 CLI 缺失影响；登出清本项目凭据和缓存，停止续期，重新登录可恢复查询 |
| R004 | 支持手动刷新；关闭浮窗不退出应用；提供退出入口 | 手动刷新取得新结果后更新；关闭或 Esc 隐藏；退出结束进程并释放资源 |
| R005 | 检测 GitHub 最新正式应用版本，并提供更新提示和下载入口 | 启动后及运行期间每 24 小时后台检查；关于窗口可手动检查。正确比较数字版本，忽略草稿 / 预发布及安装包未就绪的发布。发现新版提示；无新版和自动检查失败不打断使用。手动失败可重试；用户点击才打开发布页，不自动安装 |

R001–R004 的编号保持不变。打开、轮询、快照与菜单的当前行为统一由交互需求定义：打开只展示已有状态，启动后台查询一次，可见时每 10 秒、全隐藏时每 5 分钟轮询，支持跨重启历史快照。

## 数据要求

- `percent` 是已用百分比；有效时剩余为 `clamp(100 - percent, 0, 100)`。没有有效 `percent` 时，才用有效的 `used >= 0`、`total > 0` 换算。
- 缺失、非法数值及不能计算的结果标为未知，不补 0。`total=0` 无法用于换算百分比或剩余量；独立有效的 `percent` 仍可使用。
- 越界截断须提示数据异常；`used` / `total` 单位尚未证实，展示为“额度”。
- 区分服务端重置时间、服务端数据更新时间与本地查询时间；不从非法日期推断“现在”。
- 产品或周期错误单独标注，不能当作未订阅；未知订阅状态不能当作有效订阅。
- refresh token 仅以 DPAPI CurrentUser 加密保存；STS 和完整授权码仅在内存，不输出日志。历史快照按会话 scope 隔离，不存原始身份标识。

| 输入 | 期望展示 |
| --- | --- |
| `used=250, total=1000, percent=25` | 剩余 75%，剩余额度 750 |
| 只有 `percent=25` | 剩余 75%，绝对量未知 |
| 无有效 `percent`，`used=250, total=1000` | 换算剩余 75%，剩余额度 750 |
| 无有效 `percent`，`total=0` 或数值缺失 | 剩余百分比未知，不能伪造 0 |
| 某周期返回 `error` | 该周期错误，其他可用周期照常展示 |

## 范围边界

不包含套餐购买、升级、退订、API Key 管理、账户余额、资源包、账单、Token 计费统计、TTS / ASR 用量、预算控制与额度告警。当前不启用开机自动启动，也不提供多账号管理或跨平台版本。

Agent Plan 个人版使用独立浏览器登录会话和直接签名请求；应用不监听回调，用户在登录窗口主动粘贴完整回调 URL 并提交。STS 到期前自动续期，续期失败重新打开手动回调登录。其他 ArkCLI 能力保留，不借本次切换扩展或删除其他套餐与 Runtime 功能。具体契约见 [直连说明](../direct-agent-plan.md)。
