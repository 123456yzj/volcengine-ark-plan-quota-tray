# ark_left v0.21.0

Windows 火山方舟 Agent Plan 个人版额度托盘工具，首次提供按用户安装的 Windows 安装包。

- 悬浮圆圈显示剩余额度，详情展示 5 小时、周、月窗口与订阅类型，支持手动刷新。
- “设置 → 重新登录”打开浏览器授权；复制授权后的完整回调 URL，粘贴到应用窗口提交。
- “设置 → 登出”清除本项目登录会话与额度缓存；refresh token 和额度缓存使用 Windows DPAPI 加密。
- 安装无需管理员权限，提供开始菜单入口、可选桌面快捷方式和卸载功能。
- 包含官方 ArkCLI bootstrap 与第三方许可；个人版额度登录与查询直接连接方舟服务。

下载 `ark_left-0.21.0-windows-setup.exe` 后运行。需要 Windows 10 / 11 与 .NET Framework 4.8。可使用同页的 `SHA256SUMS.txt` 校验下载文件。

升级前从托盘退出旧实例。卸载保留用户状态，彻底清除方法见项目的 `docs/setup.md`。首次登录入口为圆圈或托盘右键菜单“设置 → 重新登录”。

已知验证边界：安装包尚未进行代码签名；全新 Windows、ARM64 原生执行、多屏 / 高 DPI 和真人托盘交互尚未完成验收。个人版以外的套餐不在本次发布的真实数据验收范围内。详细验证记录见 `docs/verification.md`。
