# 本地使用指南

本指南以当前分支说明运行方法。额度交互基线为 v0.18.1 UX026，应用 v0.21 使用 [手动提交回调的直连登录与查询](direct-agent-plan.md)。

## 启动

从 [GitHub Releases](https://github.com/123456yzj/volcengine-ark-plan-quota-tray/releases/latest) 下载 `ark_left-<版本>-windows-setup.exe`。安装需要 Windows 10 / 11 与 .NET Framework 4.8，默认目录为 `%LOCALAPPDATA%\Programs\ark_left`，无需管理员权限。开始菜单的 ark_left 入口总是显示悬浮圆圈；安装时可选创建桌面快捷方式。首次登录使用下方“设置 → 重新登录”流程。

升级前先从托盘菜单退出旧实例，再运行新版安装包并安装到原目录。卸载使用 Windows“设置 → 应用”或开始菜单卸载入口；卸载保留 `%LOCALAPPDATA%\ark_left` 的登录与偏好数据。需要清除登录时先在应用内登出，完全清理时在退出应用后手动删除该状态目录。

发布构建使用 `package.ps1`，要求 Inno Setup 6；可传 `-IsccPath 'C:\path\to\ISCC.exe'` 与 `-OutputDir 'dist'`。脚本调用现有构建、读取 exe 版本号，再生成安装程序和 SHA-256 文件。安装内容按清单选取，不包含单测程序、测试状态或本机凭据。安装程序缺少 .NET Framework 4.8 时会提示并终止，不自动下载组件。

需要 Windows 与 .NET Framework 4.8。双击项目根目录 `start.cmd`，或运行构建目录的 `ark_left.exe --show`。首次运行显示悬浮圆圈，之后无参数启动静默驻留；重复启动唤起已有实例。

Agent Plan 个人额度查询不需要 ArkCLI 登录或本机 AK/SK。仍保留的 ArkCLI Runtime 诊断、更新和独立检查使用自己的组件，配置见 [managed-runtime.md](managed-runtime.md)，不参与额度认证与请求。

Windows 可能将托盘图标放入隐藏图标区；可展开任务栏角落箭头，将图标拖到可见区域，或在任务栏设置中启用显示。

## 登录与组件诊断

点击托盘或圆圈右键菜单“设置 → 重新登录”，先打开浏览器，再弹出置顶的回调输入窗口。首次登录也使用此入口。可移动或最小化弹窗，在浏览器完成登录和授权后回来填写。窗口提供“复制登录链接”和“打开浏览器”。授权后浏览器可能显示本机回调页面无法访问；直接复制地址栏中的完整 URL（包含 `code` 和 `state`），粘贴到登录窗口，点击“提交回调”。应用不启动回调监听，也不自动读取地址或剪贴板。

校验失败会提示重新粘贴，不关闭窗口；必须使用本次登录生成的回调地址。可点击“取消”、按 Esc、关闭登录窗口或使用“设置 → 取消登录”；等待上限 10 分钟。

显式登录暂停新查询、取消旧查询并清旧展示及缓存；成功后直接查询 GetAFPUsage。refresh token 用 DPAPI CurrentUser 加密保存，STS 只在内存；到期前自动续期，失败重新拉起网页登录。重新网页登录建立新缓存绑定，正常续期保持绑定。

“设置 → 登出”取消正在进行的登录、查询和续期，清除本项目的 refresh token、内存 STS、额度展示和历史缓存。成功后保持未登录；需再次使用“重新登录”恢复查询。凭据删除失败会提示登出未完成，可重试。

“关于 / 诊断”保留 ArkCLI Runtime 状态与更新检查。组件缺失不阻塞个人额度直连；`ARK_LEFT_CLI` 仅影响仍保留的 ArkCLI 能力。

开发或诊断可在 PowerShell 中设置当前会话覆盖，然后从同一会话启动：

```powershell
$env:ARK_LEFT_CLI = 'C:\path\to\arkcli.exe'
.\bin-v21\ark_left.exe --show
```

覆盖必须是存在的绝对 `.exe` 路径；已有实例须先正常退出才能使用新的环境。无效覆盖会明确失败。

## 查看与刷新

- 托盘左键切换圆圈；圆圈左键或 Enter / Space 打开全部额度详情。打开与重复唤起只展示已有状态，不查询；无历史时显示“暂无数据”。
- 悬浮圆圈不弹出 tooltip；设置保存失败使用托盘通知。
- 圆圈显示选定套餐 / 周期的剩余百分比，拖动位置只在本次运行有效，不保存坐标。选择目标缺失时显示“暂无数据”，保留选择。
- 共享菜单第一级为设置、隐藏 / 显示、关于 / 诊断、退出；账号操作位于设置子菜单。“设置 → 悬浮内容”直接保存选择并按已有数据生效；写失败保留旧选择。
- 详情卡片右键菜单为刷新、复制摘要、设置、关闭。“设置”打开选择弹窗，取消、Esc 或 Alt+F4 不保存；保存失败保持弹窗打开。
- 详情首行显示订阅类型与最近更新时间，右侧“刷新”按钮可直接更新额度；仅时间变化时原位更新，失败保留上次成功时间。
- 详情含焦点且设置 / 菜单未打开时，精确 Ctrl+R 手动刷新，Ctrl+C 复制摘要。摘要只包含展示额度和时间，不含原始身份或上游错误文本。
- 启动后台查询一次；圆圈或详情可见时每 10 秒轮询，全隐藏时每 5 分钟轮询。仅设置弹窗可见不提速，显隐变化不立即查询；在途重复刷新不排队。
- 等待结果期间保持界面、焦点和滚动。普通失败保留历史与原查询时间；明确未登录或身份变化清旧数据。关闭、Esc 或失焦隐藏详情，应用继续驻留；“退出 ark_left”结束应用。

Agent Plan 个人版左侧详情弹窗展示 5 小时、每周、每月窗口与接口套餐档位，隐藏每日 AFP。接口解析与缓存仍保留每日窗口。剩余百分比由 `Used` / `Quota` 按原有规则换算；未知与真实 0 区分，单位统一称“额度”。其他套餐的已有兼容能力不在本次切换范围。

## 本地文件与隐私

应用状态默认位于 `%LOCALAPPDATA%\ark_left`，可用 `ARK_LEFT_STATE_DIR` 隔离：

| 文件 | 内容 |
| --- | --- |
| `first-run.done` | 版本 / 日期标记；删除后下次启动再次显示圆圈，不改变登录状态 |
| `quota-cache.dat` | DPAPI CurrentUser 加密历史快照与不可逆 scope 指纹；仅 Same 的成功类结果保存 |
| `direct-session.dat` | DPAPI CurrentUser 加密 refresh token 与随机会话绑定；不含 STS、授权码或原始账号信息 |
| `floating-settings.json` | 格式 1，明文产品 / 周期标识，无身份、额度或坐标 |
| `floating-preferences.json` | 格式 2，位置锁定 / 减少动画两个布尔，严格格式 1 可只读迁移 |

除加密 refresh token 外，不保存 SK、SessionToken、授权码或原始账号身份。普通失败保历史；明确未登录、新 scope 或 Mismatch 清历史。损坏快照按无缓存处理。

正式登录/查询及命令行验证见 [直连说明](direct-agent-plan.md)，业务状态格式见 [contracts.md](contracts.md)。其他 ArkCLI Runtime 生命周期方案见 [managed-runtime.md](managed-runtime.md)。
