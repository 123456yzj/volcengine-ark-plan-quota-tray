# 本地设置指南（setup）

本文件是 `ark_left` 的**本地离线设置指南**，可直接用文本编辑器打开。
v0.13 UX021（T050 主代理 2026-10-04 已独立验收接受）延续**悬浮圆圈**默认入口，并在圆圈或详情可见时每 10 秒轮询；
点击圆圈查看全部额度，右键圆圈可设置要显示的套餐 / 周期、锁定位置、减少动画、把悬浮窗归位。
详情可见且含焦点时支持 `Ctrl+R` 刷新与 `Ctrl+C` 复制摘要（v0.13 新增）。
本指南**不联网**、**不执行登录或安装**，只说明如何准备数据来源。

## 1. 前置：ArkCLI

`ark_left` 不自行存储凭据，数据来自本机已登录的 **ArkCLI**。请先在本机安装 ArkCLI
（请使用你获得 ArkCLI 的官方渠道；本应用不代为下载或安装）。

安装完成后，可先确认命令可用：

```
arkcli --help
```

## 2. 登录方舟账号

在本机终端执行：

```
arkcli auth login volc-sso
```

登录成功后，可在终端用以下命令确认登录状态（输出 JSON）：

```
arkcli auth status --format json
```

其中 `logged_in` 为 `true` 表示已登录。`ark_left` 以同名认证闸门为准：**只有确认已登录才查询额度**。

## 3. 应用找不到 CLI 时：设置 `ARK_LEFT_CLI`

`ark_left` 按以下顺序查找**原生 `arkcli.exe`**：

1. 环境变量 `ARK_LEFT_CLI`；
2. `PATH` 中的 `arkcli.exe`；
3. npm shim 目录下
   `node_modules/@volcengine/ark-cli/bin/arkcli-windows-amd64.exe`。

若提示“未找到本机 ArkCLI”，可设置 `ARK_LEFT_CLI` 指向 `arkcli.exe` 的**绝对路径**
（必须是存在且以 `.exe` 结尾的绝对路径）。例如在 PowerShell 中：

```powershell
setx ARK_LEFT_CLI "C:\path\to\arkcli.exe"
```

设置后需要**重新启动** `ark_left` 才能生效。

> 说明：本应用**仅支持原生 `.exe`**，不支持 PowerShell `.ps1` shim。

## 4. 刷新额度

- 打开浮窗（含右键“查看全部额度”和重复启动唤起）只显示已有状态，零查询；
- **左键点击圆圈**（或键盘 Enter / Space）打开全部额度详情，**零查询**；详情关闭回到圆圈；
- **右键点击圆圈**弹出与托盘一致的 8 项共享按钮组：**查看全部额度 / 设置 / 锁定位置 / 减少动画 /
  悬浮窗归位 / 隐藏悬浮窗 / 分隔 / 退出 ark_left**。“设置”弹窗用 `ComboBox` 选择要显示的套餐 / 周期，
  **保存后立即按已有数据展示、零查询**，失败会短提示且不应用；`Esc` / 取消 / `Alt+F4` 不保存，
  关闭后回原详情并保留焦点 / 滚动；选择**跨启动记忆**在本机状态目录，仅存产品与周期标识、不含凭据。
  “锁定位置”只阻止鼠标拖动，不阻止点击查看详情；位置仍仅本会话有效、不持久化坐标。
  “减少动画”停止水波动画并重绘静态波面；偏好跨启动记忆（`floating-preferences.json` 格式 2，
  只读迁移严格格式 1）。“悬浮窗归位”把圆圈移回**当前圆圈所在屏**工作区右下（未定位时取 primary 屏），
  按该屏 DPI 的 136dp；锁定不阻止归位，归位不查询、不保存坐标。
- 详情 footer 右侧的**「复制摘要」**按钮属于**详情面板**（不是右键菜单项），只在点击**或详情内 `Ctrl+C`** 时写剪贴板，
  复制当前已渲染额度与最后成功更新时间，不含上游错误 / 身份原文。
- 每次启动后台立即查询一次；此后**圆圈或全部额度详情任一可见时每 10 秒**轮询，
  **两者都隐藏时每 5 分钟**轮询（隐藏仍继续；仅设置弹窗可见、圆圈与详情均隐藏时**不**提速）；可见性变化不立即查询。
- 详情面板的“刷新”按钮**或详情内 `Ctrl+R`** 可重新查询，在途重复触发不排队；等待期间界面保持；
- 失败短提示保留上次成功数据与原时间；无缓存固定“暂无数据”。

数值口径：以**剩余百分比为主**，`percent` 是**已用**百分比，剩余 = `100 - percent`；
缺失 / 未知与真实 `0` 严格区分，失败不会显示为 0。

## 5. 托盘图标看不到（被折叠）

Windows 可能把新图标收入“**隐藏的图标 / 折叠区**”。处理方式：

1. 点击任务栏角落的向上箭头（`^`）展开隐藏图标；
2. 将 `ark_left` 图标拖到任务栏可见区域；
3. 在“任务栏设置 → 选择哪些图标显示在任务栏上”中把 `ark_left` 设为显示。

这是 Windows 的系统行为，`ark_left` 不保证图标始终直接可见。

首次运行时应用打开**悬浮圆圈**；之后启动将**静默驻留**，不自动弹出详情。
圆圈默认在当前屏右下角，可用鼠标拖动（位置仅本会话有效、下次启动回到右下初始位）。
若要强制显示圆圈便于验证，可运行 `bin-v13\ark_left.exe --show`（当前 v0.13，主代理 2026-10-04 已独立验收接受并在授权内本地升级运行，PID 15260）；
历史 `bin-v05` 示例已由 v0.12 / v0.13 取代（v0.12 记录为历史）。也可直接双击 `start.cmd`，由 `launch.ps1` 处理旧实例并启动 `bin-v13`。

## 6. 隐私

- 应用**不直接读取凭据文件**、不展示、不持久化任何凭据字段；
- 额度快照与不可逆 scope 指纹由 DPAPI CurrentUser 保护，原始身份与凭据不落盘；
- 应用自身不联网，数据来自本机 ArkCLI 子进程。

## 7. 本地状态文件

首次运行标记位于：

```
%LOCALAPPDATA%\ark_left\first-run.done
```

同目录 `quota-cache.dat` 为 DPAPI 加密历史快照（格式1），成功且身份 Same 才保存；损坏忽略。
明确未登录 / 新 scope / Mismatch 清历史，普通失败保持旧数据及时间，Unknown 不替换确认历史。

同目录另有 identity-free 偏好与选择文件：`floating-settings.json`（格式1，仅产品 / 周期标识）、
`floating-preferences.json`（格式2，仅位置锁定 / 减少动画两个布尔；读取严格格式1 只读迁移），
均不含凭据、身份或位置坐标。

marker **仅含日期 / 版本标记**，不含身份、额度或凭据。删除它只会在下次启动时再次打开面板，
不影响已登录状态。测试或隔离运行可用环境变量 `ARK_LEFT_STATE_DIR` 指定其它目录。
