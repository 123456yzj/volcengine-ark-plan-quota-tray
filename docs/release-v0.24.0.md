# ark_left v0.24.0

新增主题色设置：在“设置”内切换强调色预设（默认蓝、青绿、翠绿、紫罗兰、暖橙、玫红）与深色内容面。

- 设置弹窗在“悬浮内容”下方新增主题区域；选择即时预览，点“保存”持久化，取消 / Esc / 关窗回滚。
- 主题随偏好跨启动记忆（偏好文件格式 3，自动迁移旧格式 1 / 2），默认主题与历史配色逐字节一致。
- 主题统一驱动详情内容面、圆圈内容面、按钮 / 菜单 / 圆角用色；深色模式只改变内容面与文字对比。

下载安装 `ark_left-0.24.0-windows-setup.exe`。先退出旧版，再安装到原目录。要求 Windows 10 / 11 与 .NET Framework 4.8；安装包不包含 .NET，也不自动下载安装 ArkCLI。下载校验使用本页 `SHA256SUMS.txt`。
