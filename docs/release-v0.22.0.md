# ark_left v0.22.0

新增应用更新检测。启动约 15 秒后后台查询 GitHub 最新正式版，运行期间每 24 小时检查一次；发现新版时，同一版本每次运行只发送一次托盘提示。

“关于 / 诊断”显示当前应用版本，并提供“检查应用更新”和“打开下载页面”。网络失败可重试；只有用户点击才打开对应 GitHub Release，下载安装仍由用户操作。检查使用匿名 GitHub API，不发送方舟凭据。

ArkCLI 更新入口保留在窗口内的“ArkCLI 组件诊断”，与应用更新分别显示。保留 v0.21.1 的高 DPI 圆圈文字修复、直连登录及既有额度展示。

下载安装 `ark_left-0.22.0-windows-setup.exe`。已有用户先退出旧版，再安装到原目录；安装保留登录状态与显示偏好。发布同时提供 `SHA256SUMS.txt`，可通过 PowerShell `Get-FileHash -Algorithm SHA256` 校验下载文件。

已知限制：当前仓库为私有仓库，匿名 GitHub 更新接口返回 HTTP 404，因此本版本的应用内更新检测暂时无法获取最新版本；后台失败不会打断额度功能，手动检查会显示失败提示。此版本按用户要求先行发布，公开发布源或私有鉴权留待后续处理。下载 Release 需要登录具有仓库访问权限的 GitHub 账号。

验证：构建通过，完整测试 2896 项断言通过、0 失败；启动器及真实安装、覆盖安装、卸载和安装后单实例交互检查通过。真实匿名联网检测未通过，原因与上述限制一致。
