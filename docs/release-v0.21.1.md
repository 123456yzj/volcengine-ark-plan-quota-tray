# ark_left v0.21.1

修复 v0.21.0 在部分高 DPI 电脑上悬浮圆圈文字被截断的问题：`100%` 只显示 `100`，额度变为 `5E+4 A…`。

- 圆圈文字改为像素字体，避免显式屏幕缩放与 Point 字体 DPI 转换重复放大。
- 百分比根据实际文字宽高适配显示区域；额度使用与绘制一致的文字测量，完整保留 AFP 单位。
- 新增 100 / 125 / 150 / 175 / 200% 缩放与 96–192 绘图 DPI 的回归检查，候选全量测试 2835 项通过、0 失败。

下载 `ark_left-0.21.1-windows-setup.exe`。先从旧版托盘菜单退出，再安装到原目录；保留已有登录与偏好。要求 Windows 10 / 11 与 .NET Framework 4.8，无需管理员权限。

安装包尚未做代码签名。已验证模拟 DPI 渲染；用户反馈电脑及混合 DPI 多屏的人工复测仍待完成。下载校验见同页 `SHA256SUMS.txt`。
