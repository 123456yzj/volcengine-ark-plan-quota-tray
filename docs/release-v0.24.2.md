# ark_left v0.24.2

修复主题弹窗在高 DPI 下字体过大、标签裁切的问题。

- 主题字体改用物理像素尺寸，只应用一次 DPI 缩放；主题标题、主题色标签、深色内容面开关及按钮恢复正常比例。
- 增加 100%～250% 的字体回归检查，并检查 175%／200% 的合成显示预览。

下载安装 `ark_left-0.24.2-windows-setup.exe`。先退出旧版，再安装到原目录，保留已有登录与偏好。要求 Windows 10 / 11 与 .NET Framework 4.8；安装包不包含 .NET 或 ArkCLI。下载校验使用本页 `SHA256SUMS.txt`。

验证：DPI 字体专项 75 项断言通过、0 失败；主题专项 460 项断言通过、0 失败；窗口显隐与单实例集成检查通过。最终安装包通过静默安装、快捷方式、安装后显隐与单实例、覆盖安装及旧组件清理、卸载与用户状态保留检查；详细记录见仓库 `docs/verification.md`。

已知验证限制：全量回归为 2861 通过、12 失败，失败集中在圆圈原生命中检查，实际命中 Explorer 窗口，原因尚未确认（T-059）；既有 GUI 冒烟圆圈 1% 水位像素断言仍失败（T-058）。真实高 DPI 首次显示与整体 GUI 人工验收尚未完成。本轮未重新执行真人浏览器授权、多屏、读屏、全新 Windows 或 ARM64 原生验收。安装包尚未代码签名。
