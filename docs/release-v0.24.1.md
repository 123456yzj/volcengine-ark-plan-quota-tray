# ark_left v0.24.1

主题入口移至圆圈 / 托盘右键菜单第一级，点击“主题”打开独立弹窗。详情界面清理并修复刷新闪屏。

- 独立主题弹窗提供六种强调色预设与深色内容面开关，选择即时预览，保存后跨启动记忆；取消、Esc 或关窗回滚。保存失败保留弹窗并提示。
- 删除旧设置弹窗，保留“设置 → 悬浮内容 / 登出 / 重新登录”子菜单。
- 删除详情右键菜单、额度摘要复制、Ctrl+C 与全部详情 tooltip；首行刷新按钮和 Ctrl+R 保留。
- 详情刷新使用整窗合成绘制；同数据更新时间原位更新，主题预览后恢复详情焦点与滚动。
- 本地启动入口默认使用 bin-v24，正常关闭项目旧实例后启动当前构建。

下载安装 `ark_left-0.24.1-windows-setup.exe`。先退出旧版，再安装到原目录。要求 Windows 10 / 11 与 .NET Framework 4.8；安装包不包含 .NET 或 ArkCLI，保留用户登录和偏好。下载校验使用本页 `SHA256SUMS.txt`。
